# 수료 실습 — ship

배송비 규칙을 혼자서 TDD 로 구현합니다 (Day 2 수료 실습).

이 실습에는 정해진 프롬프트가 없습니다. 과정에서 쓴 템플릿(`../../프롬프트_템플릿.md`)을
직접 채워서 씁니다. 평가는 **프롬프트가 아니라 테스트와 기록**으로 합니다.

## 진행 순서
1. 요구사항을 예시 표로 만든다 (경계값 양쪽 포함) — `docs/예시표.md`
2. `GEMINI.md` 를 만든다 (cart 의 규칙을 참고)
3. 테스트를 직접 하나 쓰고 RED 를 확인한다 (`NotImplementedError`)
4. GREEN 템플릿으로 최소 구현을 받는다 → 통과 확인
5. 반복. 모두 통과하면 REFACTOR 템플릿으로 한 가지씩 정리
6. REVIEW 템플릿으로 빠진 경계값을 점검한다

## 프롬프트에 꼭 들어가야 할 네 가지
- 대상 파일 (`@tests/...` `@src/...`)
- 범위 (`... 만`)
- 금지 (`테스트 파일은 수정하지 마`)
- 확인 (`끝나면 !pytest -q --tb=short 결과를 보여줘`)
