# 배송비 계산기 — 테스트 플랜

계약표의 각 규칙을 테스트 케이스(TC)로 펼친 표. 경계값은 **짝**으로 쓴다.

| TC | 계약 | 유형 | 입력 (order_amount, grade) | 기대 결과 | 테스트 함수 |
|---|---|---|---|---|---|
| TC-01 | CT-1 | 일반 | 10,000 · NORMAL | 3,000 | test_basic_fee_is_3000 |
| TC-02 | CT-2 | 경계 (바로 아래) | 29,999 · NORMAL | 3,000 | test_free_shipping_boundary[29999-3000] |
| TC-03 | CT-2 | 경계 (정확히) | 30,000 · NORMAL | 0 | test_free_shipping_boundary[30000-0] |
| TC-04 | CT-3 | 오류 | 0 | ValueError | test_non_positive_amount_raises[0] |
| TC-05 | CT-3 | 오류 | -1 | ValueError | test_non_positive_amount_raises[-1] |
| TC-06 | CT-4 | 경계 (바로 아래) | 19,999 · GOLD | 3,000 | test_gold_free_shipping_boundary[19999-3000] |
| TC-07 | CT-4 | 경계 (정확히) | 20,000 · GOLD | 0 | test_gold_free_shipping_boundary[20000-0] |
| TC-08 | CT-5 | 회귀 | 20,000 · NORMAL | 3,000 | test_normal_member_keeps_30000_rule |
| TC-09 | INV-1·2 | 골든 마스터 | 등급 2종 × 금액 10종 | 리팩터링 전후 동일 | test_golden_master |

우선순위: 경계(TC-02·03·06·07)와 회귀(TC-08)를 먼저 쓴다.
