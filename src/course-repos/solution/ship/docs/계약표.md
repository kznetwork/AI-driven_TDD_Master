# 배송비 계산기 — 계약표 (Contract)

요구사항 → **계약**(입력 조건 · 출력 · 오류)으로 바꾼 표. 테스트의 기대값은 여기서 온다.

| 계약 ID | 요구 | 규칙 | 사전조건 (입력) | 사후조건 (출력) | 오류 |
|---|---|---|---|---|---|
| CT-1 | 요구 1 | 기본 배송비는 3,000원 | 0 < order_amount < 30,000 | 3,000 | — |
| CT-2 | 요구 2 | 30,000원 이상이면 무료 | order_amount ≥ 30,000 | 0 | — |
| CT-3 | 요구 3 | 0원 이하는 오류 | order_amount ≤ 0 | — | ValueError |
| CT-4 | 요구 4 | GOLD 는 20,000원 이상이면 무료 | grade="GOLD" 이고 order_amount ≥ 20,000 | 0 | — |
| CT-5 | 요구 4 | grade 를 생략하면 NORMAL (기존 규칙 유지) | grade 생략 | NORMAL 과 동일 | — |

## 불변식 (Invariant)

| ID | 항상 지켜야 하는 성질 |
|---|---|
| INV-1 | order_amount > 0 이면 배송비는 0 또는 3,000 둘 중 하나다 |
| INV-2 | 같은 등급에서 주문 금액이 늘어나도 배송비는 늘어나지 않는다 |

## 열린 질문 (Open Question)

| ID | 질문 | 결정 |
|---|---|---|
| OQ-1 | grade 가 NORMAL · GOLD 가 아니면? | 이번 범위 밖 — 호출하는 쪽의 사전조건으로 둔다 (결정: 강사) |
| OQ-2 | order_amount 가 소수이면? | 이번 범위 밖 — 정수 금액만 다룬다 |

범위 밖: 도서산간 추가 배송비 · 쿠폰 · 포인트
