# gemini Practice Calculator

A simple TypeScript calculator project for practicing gemini file and folder references.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- TypeScript strict mode

## Project structure

```text
src/
├── index.ts
├── config.ts
└── utils/
    └── math.ts
```

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
